# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub instead: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/Haythamasalama/easyshoot/security/advisories/new)).

Include the affected version, steps to reproduce and the impact you expect. You can expect an initial reply within a few days. Accepted reports will be fixed and credited in the advisory, unless you prefer to stay anonymous.
